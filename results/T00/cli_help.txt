$ target/release/leanvm --help
Usage: leanvm [OPTIONS] <COMMAND>

Commands:
  aggregate  Prove signatures and blobs, then verify the proof. At least one count must be nonzero
  recursion  Aggregate n child proofs into one proof
  hash       Prove and verify a batch of Keccak-f permutations with the VM's GKR, outside the VM
  fibonacci  Prove and verify Fibonacci in the exponent (demo)
  help       Print this message or the help of the given subcommand(s)

Options:
      --log-inv-rate <LOG_INV_RATE>  WHIR inverse-rate logarithm (1 through 4) [default: 1]
      --tracing                      Enable hierarchical timing traces. Use RUST_LOG to adjust verbosity
      --repeat <REPEAT>              Measured proving passes after warmup [default: 1]
      --cooldown <COOLDOWN>          Idle seconds before each measured pass [default: 2]
  -h, --help                         Print help

$ target/release/leanvm recursion --help
Aggregate n child proofs into one proof

Usage: leanvm recursion [OPTIONS]

Options:
      --log-inv-rate <LOG_INV_RATE>
          WHIR inverse-rate logarithm (1 through 4) [default: 1]
      --n <N>
          Number of child aggregates [default: 2]
      --tracing
          Enable hierarchical timing traces. Use RUST_LOG to adjust verbosity
      --xmss-per-leaf <XMSS_PER_LEAF>
          leanXMSS signatures in each child. Sets the child proof's committed size, which is what the recursion cost should be quoted against [default: 900]
      --repeat <REPEAT>
          Measured proving passes after warmup [default: 1]
      --sphincs-per-leaf <SPHINCS_PER_LEAF>
          leanSPHINCS signatures in each child, on top of the leanXMSS ones [default: 0]
      --blobs-per-leaf <BLOBS_PER_LEAF>
          Blobs in each child's LeanDA commitment. Use --xmss-per-leaf 0 for blobs alone [default: 0]
      --cooldown <COOLDOWN>
          Idle seconds before each measured pass [default: 2]
      --leaf-log-inv-rate <LEAF_LOG_INV_RATE>
          WHIR inverse-rate logarithm of the leaves (1 through 4)
  -h, --help
          Print help
